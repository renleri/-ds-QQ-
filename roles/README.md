# 角色扮演文件

**只有管理员（`config.json` 的 `ownerQQ`）能切换角色**；其他人说这句话会被直接拦下并回一句提示，
不会转发给模型。管理员在**群里或私聊**都可以，两种说法等价：

```
进入角色扮演：<角色名>      ← 自然语言，和下面 /role 效果完全一样
/role <角色名>             ← 斜杠命令

退出角色扮演
/role off                  ← 清除角色，恢复正常人格
```

切换后，桥接会把 `roles/<角色名>.md` 的**全文**拼在每条消息最前面注入给 agent
（长度上限见 `config.json` 的 `social.roleMaxChars`，默认 12000 字符）——
群友无法通过对话改角色，只能由管理端改文件或发上面这些命令。

## 其它管理命令（同样仅管理员）

| 命令 | 作用 |
|---|---|
| `/status` | 查看会话 ID / 白名单是否通过 / 当前角色 / 模式 |
| `/silent` | 静默模式：群友消息不回复，仅管理员可对话 |
| `/active` | 退出静默模式 |
| `/reset` | 重置会话上下文，下次消息开新上下文 |

## 文件格式

每个角色一个 Markdown 文件，文件名 = 角色名（不含扩展名，中英文均可，**可以用《》**）。示例：

```markdown
# 角色名（可自定义，如：傲娇助手）

- 性格：傲娇、嘴硬心软，被夸会不好意思
- 说话风格：简短、带哼声（"哼！"），偶尔用 emoji
- 背景设定：你是管理员的老朋友，说话可以随意一点
- 与群友的互动规则：对每一条 @ 你的消息都回应，但不主动插话
- 特殊能力：可以用 QQ 工具帮群友查天气、找资料（正常使用 mcp__snowluma__ 工具）
```

### 角色卡自己的配置（可选）

角色卡顶部可以写**机器可读指令**，用来覆盖全局设置。写法是 HTML 注释，
**不会被注入给模型**（她看不到，也不占上下文）：

```markdown
<!-- @maxMessageChars: 20 -->
```

| 指令 | 作用 | 全局兜底 |
|---|---|---|
| `@maxMessageChars` | 这一份角色卡单条消息的字数上限（超长会被发送工具直接拒绝） | `config.json` 的 `socialV2.send.maxMessageChars` |

典型用法就是「同一套人格，两种说话风格」——原版允许长句，`《人》`版限制 20 字。

## 提示

- 角色名建议用简短中文（如 `傲娇助手`、`猫娘`、`吐槽役`）
- 想换性格直接改文件内容，再发一次 `进入角色扮演：<角色名>` 即可生效（无需重启桥接）
- 角色设定里可以要求保留某些工具能力（发消息、查群），也可以限定"只聊天不干活"
- 本目录现有的角色卡：
  - `鲸鱼娘.md` —— **原版**：`【PERSONA_LOAD】` 原始规格，可以用括号写尾鳍动作，长句不限
  - `鲸鱼娘《人》.md` —— **装成普通群友的版本**：口语化、单条 ≤20 字、不用括号动作、不提 AI 身份
  - `二阶堂希罗.md` —— 《魔法少女ノ魔女裁判》的角色扮演卡：礼貌敬语但冰冷高压，
    非黑即白的「正确／不正确」审判腔，单条 ≤50 字（卡内自带 `<!-- @maxMessageChars: 50 -->`）
  - `小鲸鱼.md`（完整版）、`傲娇助手.md`（示例）

切换示例：

```
/role 鲸鱼娘《人》
/role 二阶堂希罗
/role 鲸鱼娘
```
